# Security and autonomy boundary

- Provider credentials belong only in server environment variables.
- The browser must never receive provider API keys.
- The agent may research, personalize outreach, qualify and prepare a handoff.
- The agent must stop before payment, contract acceptance or other irreversible commercial action.
- Outreach integrations must implement provider/platform rules, rate limits, opt-out handling and suppression lists.
- Verified facts only: no fabricated testimonials, results, urgency, identity or scarcity.
- Every autonomous action should emit an audit event.
